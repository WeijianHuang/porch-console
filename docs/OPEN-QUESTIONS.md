## 三、不需要再确认（后端已冻结，照做即可）

- `X-Shop-Id` 必带、缺头 `400 SHOP_CONTEXT_REQUIRED`；切换纯客户端零写入；缓存键含 `current_shop_id`（ADR-0006）。
- 错误按 `error.retryable` 判定重试；`5xx` 最多 3 次且复用同一 `Idempotency-Key`；`4xx` 不重试（`design/03` §4）。
- 单币种 CNY（`¥`）、统一 UTC+8、不传时区参数、不打印、不离线收银（ADR-0004）。
- 无门店组 / 店群；跨店范围由后端返回的可见门店集合 + 显式 `shop_ids` 驱动（ADR-0005）。
- 审计超期固定 `400 AUDIT_RETENTION_WINDOW_EXCEEDED` + `earliest_queryable_at`，不得渲染空态（ADR-0008）。
- 不做跨店自动清分、不预留外部服务回调、不假设会话粘滞或读写分离（ADR-0007 / 0008）。
